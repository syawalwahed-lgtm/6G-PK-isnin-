# Misi Pameran Kesihatan — Pendidikan Kesihatan Tahun 6

## Kandungan
- `index.html` — aplikasi pembelajaran interaktif, nota infografik, pautan carian video YouTube dan kuiz 20 soalan.
- `README.md` — panduan penggunaan dan penerbitan GitHub Pages.

## Cara guna
1. Ekstrak ZIP.
2. Buka `index.html` menggunakan Chrome, Edge, Safari atau Firefox.
3. Masukkan nama murid dan pilih tab Nota, Video atau Permainan.
4. Audio menggunakan Speech Synthesis Bahasa Melayu (`ms-MY`) jika disokong peranti/pelayar. Butang bunyi mengawal suara dan bunyi ringkas.
5. Pautan video ialah pautan carian YouTube. Guru perlu menyemak video yang sesuai sebelum PdP.

## Terbitkan melalui GitHub Pages
1. Log masuk ke GitHub dan cipta repositori baharu, contohnya `misi-pameran-kesihatan-tahun6`.
2. Muat naik `index.html` dan `README.md` ke akar repositori (Add file → Upload files → Commit changes).
3. Buka Settings → Pages.
4. Di Build and deployment, pilih `Deploy from a branch`, branch `main`, folder `/(root)`, kemudian Save.
5. Tunggu proses penerbitan selesai. GitHub akan memaparkan URL Pages dalam bahagian Pages.

## Nota kurikulum
Tema/unit dirujuk sebagai Unit 11: Pameran Kesihatan. Fokus utama nota dan kuiz ialah perubahan fizikal remaja, penerimaan diri, kebersihan, batas diri dan keputusan selamat. Sila semak kod Standard Pembelajaran tambahan dengan DSKP/RPT sekolah yang sedang digunakan sebelum menjadikan bahan ini dokumen rasmi RPH.
